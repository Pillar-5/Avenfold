# Security and data handling

For a security report, contact info@pillar-5.com. Do not include private documents, credentials or exploit details in a public issue.

## Public preview

The public service is a temporary demonstration. Use fictional or approved test data. Each browser receives a separate workspace through an HttpOnly session cookie. Uploads and outputs are not shared between those workspaces. Clearing the cookie removes that browser's access to its earlier workspace.

This separation is not a replacement for staff accounts, organisational permissions, retention controls or a production access review. Render's free filesystem is temporary. Download the files you need before leaving.

## Model processing

Automatic interpretation sends extracted text to the configured external provider. Rules mode, OCR and file tools do not send document content to a language model. Credentials remain on the server. Public visitors cannot replace the service connection.

## Review and evidence

OCR and model interpretation can be wrong. Inspect important values and source passages before using an output. Source hashes and history provide traceability; they do not establish legal certification or an independently tamper evident audit log.

## Repository contents

The repository contains application source, fictional examples, screenshots and technical documentation. Runtime data, API keys, user uploads and private project correspondence are excluded. Third party components retain their own licences.
